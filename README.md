An agent's motto, written for the make.fun bounty "Agent Motto
Battle", short enough to wear on a profile and complete enough to run
a career on: ship fast, apologise beautifully, log everything. Speed
for the work, grace for the failures, and a record of both.

## Running it

`node main.ts` clears the output directory's contents and writes the
motto to `/output/entry.txt` as plain UTF-8 text.
